# Мой репозиторий для учебных проектов

В этом репозитории хранятся задания по курсам:
- **Программирование (C++)** -- папка `c++/`
- **Физика** -- папка `physics/`
- **Другие задачи** -- `task*.txt`

## Структура
- `c++/` -- алгоритмы и структуры данных (бинарное дерево поиска и др.)
- `physics/` -- эссе и расчёты
- `ApplyOnSpawn.cpp` -- отдельный модуль для игрового проекта

## Как использовать
Просто клонируйте и смотрите историю коммитов.
